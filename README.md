# Débora Aires — Psicóloga

Site institucional em HTML estático (sem build), pronto para o GitHub Pages.

- `index.html` — conteúdo da página
- `index.css` — identidade visual e responsividade
- `script.js` — menu mobile, perguntas frequentes e formulário de contato (abre o e-mail)
- `assets/logo/` — logos oficiais em SVG (roxo e branco; horizontal, vertical e símbolo)

Dados provisórios a substituir antes de divulgar: CRP `00/00000`, e-mail `contato@deboraaires.com.br`
(em `index.html` e na constante `EMAIL_CONTATO` de `script.js`) e Instagram `@deboraaires.psi`.
